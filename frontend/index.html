วิธี L3M / L6M / LY: แบ่งหีบตามสัดส่วนที่ระบบคำนวณจากวิธีที่เลือก แล้วปรับมูลค่ารายคนให้ใกล้เป้าเงิน (±1,000 บ.) โดยหีบต่อ SKU ต่อคนไม่เกิน ±20% จากสัดส่วนนั้น — ดูแถบ ◆ / ⚠ เหนือตารางผล (กดกรอง SKU ได้)

ระบบแบ่งหีบยังไง? กดเพื่ออ่านสั้น ๆ · กดอีกครั้งเพื่อปิด

แยก SKU เป็น 2 กลุ่ม ก่อนแบ่งหีบให้ทีม

สินค้ามูลค่าสูงช่วยดึงยอดเงินให้เข้าเป้า · สินค้าที่เหลือแบ่งตามประวัติขายเดิม

  1. 1
    เรียง SKU จากมูลค่าสูง → ต่ำ

    มูลค่า = เป้าหีบ × ราคาต่อหีบ (ต่อ SKU)

    A B C …
    ~80% กลุ่มหลัก
    ~20% กลุ่มรอง
  2. 2
    กลุ่มหลัก หลัก

    เอา SKU อันดับต้น ๆ มารวมกันจนครบประมาณ 80% ของมูลค่าเป้าทั้งทีม

    • แบ่งหีบเพื่อให้ยอดเงินของแต่ละคนเข้าเป้าได้ง่ายขึ้น
    • มักเป็น SKU ไม่กี่ตัวที่มูลค่าสูงสุด (เช่น A + B ในตัวอย่างด้านบน)
  3. 3
    กลุ่มรอง รอง

    SKU ที่เหลือทั้งหมด (นอกกลุ่ม 80%)

    • แบ่งหีบตามสัดส่วนยอดขายในอดีตของแต่ละคน
    • ระบบไม่ปรับมาก — คงสัดส่วนเดิมให้ใกล้เคียงที่สุด
  4. 4
    SKU ใหม่ ใหม่ ถ้าติ๊กด้านบน

    เฉพาะ SKU ที่ทั้งทีมไม่เคยมียอดขายย้อนหลัง 12 เดือน

    • ทุกคนได้จำนวนหีบเท่ากัน — ไม่เข้ากฎกลุ่มหลัก/รอง

Dev เห็นและทำได้ทุกอย่างทั้งระบบ รวมการตั้งค่าปลายทางที่ส่งข้อมูลจริง
หัวหน้าแอดมิน เหมือนแอดมิน + เพิ่ม/ถอดสิทธิ์แอดมินคนอื่นในขอบเขตตัวเองได้ (ตั้ง Dev หรือหัวหน้าแอดมินไม่ได้)
แอดมิน จัดการผู้ใช้ / ผูกรหัส / ดูผลการดำเนินงาน ตามขอบเขตที่กำหนดให้ แต่ตั้งสิทธิ์ใครและแตะการตั้งค่าระบบไม่ได้

สิทธิ์นี้ซ้อนทับตำแหน่งเดิม — คนหนึ่งเป็นทั้ง Supervisor และแอดมินได้พร้อมกัน ตำแหน่งงานและการเห็นข้อมูลทีมยังเหมือนเดิมทุกอย่าง

ผู้ดูแล ตำแหน่งงาน สิทธิ์ ขอบเขต (แก้ผู้ใช้คนไหนได้)

ผูกรหัส SKU (รวมประวัติขาย)

แสดงเฉพาะสินค้าที่มีเป้าหีบในงวดกระจายปัจจุบัน (ดึงตามแหล่งเป้า Target Sun / Fabric) — รหัสเก่าที่เคยผูกแต่ไม่มีเป้าในงวดนี้จะไม่ขึ้น · พิมพ์รหัสเก่าในคอลัมน์「ผูกกับ」แล้วบันทึก · หลังบันทึกให้ refresh Dashboard

การผูกรหัสใช้กับประวัติขายใน Fabric ตอนกระจายหีบ (รวมยอดรหัสเก่าเข้ารหัสใหม่) — ไม่เกี่ยวกับเป้าใน Target Sun โดยตรง นอกจากการเลือกว่า SKU ไหนมีเป้าในงวดนี้
