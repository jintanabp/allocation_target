## ยังไม่แก้ (รายละเอียดใน OPEN_ITEMS หมวด 7) — ข้อที่ขีดฆ่าในย่อหน้านี้แก้แล้วตามตารางข้างบน

ข้อมูล: ดึงเป้าล้มชั่วคราวแล้วล้าง grain ดี + ข้อความผิด · ไฟล์ความเห็นผู้ใช้หายเมื่ออ่านพลาดครั้งเดียว · snapshot เสียเวอร์ชัน/สถานะส่งเมื่ออ่านพลาด ·
แคชสินค้ารวมถูกตัดเหลือทีมเดียว + race ตอนโหลดรวมภาค · log ไม่หมุน/ไม่ลบ · ล้างแคช payload บน Windows ล้มเงียบ
แกนกระจาย: สินค้าราคา 0 ไปตกคนไม่เคยขาย · LP หมดเวลาแล้วลองซ้ำอีก 60 วิ · รวมภาคตัดสินสินค้าใหม่จากทีมเจ้าของเป้าอย่างเดียว · รหัสพนักงานซ้ำได้ 409 ที่อ่านไม่รู้เรื่อง
ส่ง/ความปลอดภัย: Excel ที่ export จากแอดมินมีสูตรแฝงได้ · ตัวกันปิดล็อกอินดูแค่ `--host` · ทางส่งรวดเดียวไม่จด ledger ตอน 504 · ข้อความ error โชว์ URL เต็มของ Target Sun
หน้าเว็บ (เล็ก): ร่าง/snapshot ไม่จำโหมดประวัติ · คนหลายคลังที่คลังหนึ่งไม่มียอด 3 เดือนขึ้น "ไม่มีประวัติ" เพราะ 6/12 เดือนแบ่งคลังด้วยน้ำหนัก 3 เดือน
