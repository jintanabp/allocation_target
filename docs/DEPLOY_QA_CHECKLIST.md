## 7. ผู้จัดการ — รวมภาค

| # | ขั้นตอน | ผล | หมายเหตุ |
|---|---------|-----|----------|
| 7.1 | มุมมองรวมภาค — composite legend | | |
| 7.2 | กระจายรวมภาค + บันทึก snapshot ต่อ SL | | |
| 7.3 | **ล็อกไม่ข้ามทีม** — หาภาคที่มี ≥2 ทีมและมี `emp_id` ซ้ำกัน · แก้ตัวเลขในทีม A แล้วคำนวณใหม่ · **ทีม B ต้องไม่เปลี่ยน** | | |
| 7.4 | **ไม่มี snapshot ลงรหัสผู้จัดการ** — หลังกระจายรวมภาค ตรวจ `data/allocations/` ต้องมีแต่ไฟล์ของ SL จริง ไม่มีไฟล์ชื่อรหัส manager | | |
| 7.5 | **คำเตือน fallback ไม่หาย** — ถ้ามีทีมใดตกไปใช้ proportional แถบ「ขอให้รีเช็ค」ต้องขึ้นและ**ระบุชื่อทีม**นั้น แม้ทีมสุดท้ายจะปกติ | | |
| 7.6 | **สำเร็จบางส่วน** — ทำให้ทีมหนึ่งพัง (เช่นลบ cache เป้าของทีมนั้น) · ทีมที่เหลือต้องยังกระจายและบันทึกได้ + ขึ้นรายชื่อทีมที่พลาด | | |
| 7.7 | โหลดรวมภาคเร็วขึ้น — จับเวลาเทียบกับ `AGGREGATE_LOAD_WORKERS=1` | | |
| 7.8 | **แถวรวมทีม** — ตารางรวมภาคมีแถวสรุปท้ายกลุ่มของแต่ละซุป · หลังกระจายใหม่ต้องขึ้น「ตรงเป้าทีมทุก SKU」ทุกทีม | | |
| 7.9 | **ย้ายหีบข้ามทีมแล้วเห็น** — เพิ่มหีบให้คนในทีม A · แถวรวมทีม A ต้องขึ้น `+n` สีส้ม และทีมที่ถูกดึงต้องขึ้น `-n` สีน้ำเงิน | | |
| 7.10 | กด **คำนวณใหม่** หลังย้ายข้ามทีม — ทุกทีมกลับมา「ตรงเป้าทีมทุก SKU」 | | |
