## ฉ. ตรวจแล้วถูกต้อง (สรุป)

- ยอดหีบ: ด่านส่งเทียบกับไฟล์ขั้นที่ 1 ที่สร้างจาก TS (ไม่ใช่ค่าที่หน้าเว็บส่งมา) · ข้ามไม่ได้ · ไฟล์ = payload ทุกขั้นแปลง · /optimize บังคับยอดต่อ SKU · fuzz 600 กรณีผ่าน engine จริง ไม่มียอดเพี้ยน
- แถว TS: คีย์ 7 คอลัมน์รวมคลัง (ว่าง = ค่าหนึ่ง) · ไม่เดาคลังในทางส่ง (คู่ใหม่ = ว่าง, ไม่มี grain = 409) · ด่านคลังซ้ำตรวจซ้ำก่อน POST · ผูกรหัส SKU ไม่ remap ตอนส่ง · ย้ายพนักงานไม่สร้างคีย์ใหม่ (ไม่มีคอลัมน์ซุปในไฟล์)
- C442 (กรณีปกติ): แยกคน×คลังทุกขั้น — ขั้นที่ 2 แสดงเฉพาะ R408 · /optimize ส่งกลับแถว R408 เสมอ · ไม่ตัดทั้งคนแล้ว · เป้าของ R493 นับครั้งเดียวไปให้คนที่กระจายได้
- คนไม่ต้องตั้งเป้า: ขั้น 1–2 แสดง「ไม่ต้องตั้งเป้า」เงินโยกให้เพื่อนในทีม · /optimize ตัดออกก่อน · ส่ง 0 ทับแถวของเขา (ปิดคำถามค้าง 26 ส.ค. แล้วในโค้ด) · ยอด TS = เป้าทีม
- เป้าตั้งต้น: เขียนครั้งเดียวไม่ทับ (ใต้ล็อก) · ไม่ลบ · ทุกการโหลดเทียบ drift ลง log
- สิทธิ์: ทุก route ของทีมตรวจขอบเขต · ส่งตรวจรหัสพนักงานกับทีมผู้ส่ง · ดูแทน = dev เท่านั้นและแคบลง · debug router ปิด · ไฟล์สำคัญเขียนแบบ atomic + ล็อก
- ส่ง: กันกดซ้ำทั้งเครื่องและ server (ล็อกต่อทีม×งวด, token ใช้ครั้งเดียว) · วันที่ 1–14 ส่งไฟล์ว่างไม่ได้
- การเรียงลำดับทีม/พนักงาน ตรงกันระหว่างตัวเลือกกับตาราง
