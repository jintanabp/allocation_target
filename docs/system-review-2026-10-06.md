## ภาพรวม

- **ไม่มีข้อไหนที่แก้ไปแล้วถอยกลับ** (ไล่ commit หลัง 29 ก.ย. ทั้งหมด)
- **ตัวกระจายหีบแน่น:** จำลองสุ่ม 400 รอบ (ทุกวิธี ราคา 0 ประวัติ 0 ล็อก ฯลฯ) ยอดต่อสินค้าผิด 0 ครั้ง · ปุ่มปรับยอดอัตโนมัติ 20,000 กรณี ผิด 0 ครั้ง
- **ด่านก่อนส่งแน่น:** ไม่มีทางกดยืนยันข้ามยอดไม่ตรงแล้ว · ไฟล์ทุกใบผ่านด่านยอดต่อสินค้า = เป้า
- **แต่เจอช่องที่ "ยอดใน Target Sun หลังส่ง ≠ เป้า"** ทั้งที่ไฟล์ผ่านทุกด่าน — ต้นเหตุร่วม: ด่านดูแค่ "ไฟล์ที่ส่ง" ไม่ได้ดู "สิ่งที่ Target Sun จะมีหลังอัปเดต" (Target Sun เก็บแถวเก่าที่ไฟล์ไม่ได้ทับไว้)
